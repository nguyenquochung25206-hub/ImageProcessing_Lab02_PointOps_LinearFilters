# PLAN.md

## 1. Thông tin dự án

**Tên:** ImageProcessing_Lab02_PointOps_LinearFilters

**Mục tiêu:**  
Xây dựng chương trình xử lý ảnh bằng Python và OpenCV,
thực hiện các phép Point Operations, Linear Filters và
một số kỹ thuật xử lý ảnh nâng cao.

---

## 2. Mục tiêu chính

- Xử lý ảnh bằng các phép biến đổi điểm.
- Áp dụng các bộ lọc tuyến tính.
- Thực hiện một số thuật toán xử lý ảnh nâng cao.
- So sánh kết quả giữa các phương pháp.
- Đánh giá kết quả bằng các chỉ số MSE, MAE và PSNR.
- Xây dựng cấu trúc project rõ ràng, dễ kiểm thử và mở rộng.
